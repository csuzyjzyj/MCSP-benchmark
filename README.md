# MCSP-benchmark
README for Anonymous Multi-Crane Scheduling Benchmark

This benchmark provides anonymized task instances for the multi-crane scheduling problem studied in this work. 
All site names and workshop semantics have been anonymized, while the spatial structure, task time windows, and priority information required for scheduling are retained.

1. Workshop setting
- The workshop is modeled as a one-dimensional shared track with a total length of 360 m.
- Multiple overhead cranes operate on the same track from left to right.
- Crane traveling speed is 90 m/min.

2. Space-time discretization
To balance simulation precision and computational efficiency, the benchmark adopts a discretized representation:
- Space unit: 3 m
- Time unit: 2 s

Accordingly:
- All station coordinates provided in the benchmark are expressed in units of 3 m.
- The release times and deadlines of tasks are expressed in units of 2 s.

This discretization is used as a compromise between physical fidelity and algorithmic efficiency in simulation-based scheduling.

3. Station information
The benchmark contains a set of anonymized stations, denoted by abstract location IDs such as L01, L02, ..., L17.
Their coordinates describe their relative positions along the shared track.
These coordinates are already normalized in the 3 m space unit.

4. Task information
Each task instance is defined by the following fields:
- job_id: task identifier
- release_time: earliest allowable starting time
- deadline: latest allowable completion time
- origin: pickup location
- destination: delivery location
- priority: task priority level

No real production labels, equipment names, or process semantics are disclosed.

5. Crane layout and initial positions
Cranes are ordered from left to right along the track.
Their initial positions are randomly generated by partitioning the workshop into contiguous spatial regions according to the number of cranes.

For example:
- If there are 2 cranes in a 360 m workshop, the track may be divided into two regions:
  - Crane 1: generated in [0, 180]
  - Crane 2: generated in [181, 360]

Similarly, for more cranes, the track can be divided into multiple left-to-right segments, and each crane is initialized randomly within its assigned segment.
This setting ensures an ordered initial crane distribution and avoids unrealistic overlap at the start of simulation.

6. Anonymization note
The benchmark is derived from real industrial scheduling data, but all identifiable shop-floor semantics have been removed.
Only the abstract spatial layout, temporal constraints, and task attributes necessary for reproducible algorithm evaluation are retained.

7. Intended use
This benchmark is intended for:
- algorithm comparison in multi-crane scheduling
- testing under shared-track interference constraints
- evaluation across different task scales and crane counts

Users may directly use the provided task files and station coordinates for experimental validation without needing access to the original industrial data.
